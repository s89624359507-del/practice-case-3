Практика: Кейс-задача №3 — Django-приложение «Приветствие»
Описание проекта
Простое веб-приложение на Django, которое позволяет ввести имя, сохраняет его в базе данных и показывает персонализированное приветствие. Реализована защита от CSRF-атак.
Технологии
- Python 3
- Django 4.2
- HTML, CSS
- SQLite
Как запустить локально
1. Установи [Python](https://www.python.org/downloads/) (3.10 или новее).
2. Клонируй репозиторий или скачай файлы.
3. Открой терминал в папке проекта:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python manage.py migrate
   python manage.py runserver
   ```
4. Открой в браузере: http://127.0.0.1:8000/
Безопасность
- Все POST-формы защищены `{% csrf_token %}`.
- Валидация пустого поля на уровне формы.
- `DEBUG = True` только для разработки.
