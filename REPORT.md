Отчёт по кейс-задаче №3
1. Постановка задачи
Разработать веб-приложение на Django, которое:
- позволяет вводить имя через форму на главной странице;
- сохраняет имя в базе данных (модель с одним полем `name`);
- показывает персонализированное приветствие;
- обрабатывает ошибку пустого поля;
- имеет CSS-стилизацию;
- защищено от CSRF-атак.
2. Ход работы
2.1. Установка Django
2.2. Модель
Создана модель `UserName` с одним полем `name` (CharField, max_length=50). Сгенерирована миграция.
2.3. Форма
Создана `NameForm` на основе `ModelForm`. В методе `clean_name` реализована проверка: если имя пустое или состоит из пробелов — выбрасывается `ValidationError`.
2.4. Представление
Функция `index` обрабатывает GET (показ формы) и POST (сохранение имени). При успешной валидации имя сохраняется в БД, на странице появляется приветствие. Дополнительно выводятся последние 5 имён.
2.5. Шаблон и стили
Шаблон `index.html` содержит форму, поле ввода, кнопку Submit, блок приветствия и список последних имён. Стили вынесены в `style.css`: градиентный фон, карточка с тенью, скруглённые поля и кнопка с градиентом.
2.6. CSRF-защита
В `settings.py` подключён `CsrfViewMiddleware`, в шаблоне в форму добавлен `{% csrf_token %}`.
3. Проверка работы
- Ввод корректного имени → приветствие, имя в БД.
- Пустая форма → ошибка валидации.
- Имя из пробелов → ошибка (через `strip()`).
4. Вывод
Приложение соответствует заданию. Закреплены навыки Django: модели, формы, представления, шаблоны, миграции, CSRF-защита.
